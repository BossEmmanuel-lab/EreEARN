# Clean and Minimal Commenting Guidelines

- **No Comment Spam**: Keep code self-explanatory. Avoid adding redundant, obvious, or verbose comments throughout the codebase.
- **No Decorative Banner/Divider Lines**: Strictly never generate comments containing decorative divider lines such as `-------`, `=======`, `######`, or `///////`.
- **Allowed Comment Formats**:
  - In Python: Use standard concise `# comment` or docstrings `""" docstring """`.
  - In JavaScript/JSX: Use standard concise `// comment` or `/* comment */` without banner borders.
- **Preserve Existing Necessary Comments**: Maintain existing functional comments and docstrings unless explicitly asked to modify them.
